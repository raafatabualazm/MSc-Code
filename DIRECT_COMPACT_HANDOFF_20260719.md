# Direct compact-Qwen experiment handoff

Date: 2026-07-19

## Decision

The new path removes GraphCodeBERT, the GNN, the projector, and soft-prefix
injection. A reversible compact machine-code stream is supplied directly as
Qwen causal input IDs. The only source-specific learned component outside Qwen
is an input-vocabulary embedding table; this is an embedding lookup, not a
neural encoder. Qwen's untied output head remains at its original 151,936 rows.

The historical graph path remains intact as a baseline. Direct training and
inference use separate entry points in `hybrid_training_patch_v2_3` and cannot
silently instantiate the graph encoder.

## Why the old path was retired

The completed 490-row graph-only functional gate is stored at
`results-20260719/prefix_causality_evidence/report_490.json` (SHA-256
`6f201fd3a35b3eaab3db5f303eaf94e5756dc509d4e61842c1c245d2d0428b5f`).

- Correct versus length-matched permutation: 1 win, 488 ties, 1 loss; 0.000 pp
  effect; one-sided exact p=0.75.
- Correct versus null: 1 win, 489 ties; +0.204 pp; p=0.5.
- FACTS correct versus permutation: 490 ties.

The projected representation contained retrievable information, but the
decoder did not use it behaviorally.

## Lossless compression contract

The codec is lossless in the `scrubbed_canonical_graph` domain, not byte-lossless
with respect to the private pre-scrub assembly dump.

- Instruction text, block order, entry blocks, and CFG reconstruct exactly.
- Frequent instructions use one fitted atom; an unseen instruction uses exact
  native-Qwen fallback between reversible delimiters. There is no UNK path.
- DFG is deterministic redundant data. It is regenerated by the SHA-pinned
  extractor and must match the stored DFG edge-for-edge.
- No row is truncated. A source above 9,000 tokens fails closed.
- Only the privacy transform is intentionally irreversible: private names,
  paths, signatures, original absolute addresses, and formatting cannot be
  recovered.

## Fresh s44 holdout

`fresh_graphv2_holdout_s44.jsonl` is not training data. It was included in the
forbidden-family leakage sweep and remains sealed for evaluation. Its graph was
produced by the newer combined extractor and contains 32 explicit `call` CFG
edges, while compact x86 v1 is bound to the older release extractor and has no
`call` edge atom. It must therefore be harmonized and encoded by a versioned
codec extension before direct-model evaluation; using it for fitting or silently
dropping those edges would invalidate the experiment.

## Exact x86-64/AArch64 pairing

The historical Flutter ARM64 pool must not be merged. Although 1,712 rows link
to byte-identical original x86 sources (1,690 survive the scrubbed release), the
ARM binaries used named source while x86 used neutral `candidate`; the old ARM
records also expose source/tests/signatures/paths and lack a complete pinned
Flutter build manifest.

A four-pair pilot now proves the correct construction:

- The identical neutral Dart program bytes were compiled for Linux x64 and
  arm64 under Dart 3.11.5.
- 8 / 8 Graph-v2.1 rows and DFG regenerations pass.
- 4 / 4 JIT and x64 AOT behavior checks pass.
- 4 / 4 arm64 AOT snapshots compile and expose exact `candidate` symbols.
- ARM runtime behavior is explicitly unverified because the builder has no
  native ARM host or QEMU runtime.
- Strict model rows expose only `architecture`, `assembly`, `cfg`, and `edges`.

## GPU order and remaining gates

The direct one-step smoke is staged on the GPU pod but deliberately queues
behind both existing jobs:

1. Forced graph-causality probe.
2. Existing CLEAN@12K `02a3` decision run.
3. Direct compact Qwen3-8B one-step optimizer/reload smoke.

Pod status: `/workspace/artifacts/direct_compact_v1_smoke.status`.

The smoke trains one optimizer step, restores the paired LoRA adapter and source
embedding overlay, runs an eight-row correct/permuted/null NLL diagnostic, and
exercises cached generation. Its corrected preflight verifies the checksum
manifests and train/dev join seals. The permutation minimizes total source-length
mismatch; the null arm keeps positions fixed and zeros only source embeddings.
Training, NLL, and generation records must agree on adapter and overlay hashes
before the runner can report `passed`. Local validation is 62 / 62 patch tests
plus 26 / 26 codec/scrub/HumanEval/cross-architecture tests.

A full SFT or benchmark performance claim must not be made until that smoke
passes; behavioral source conditioning still requires a free-running
compile/pass permutation gate.
