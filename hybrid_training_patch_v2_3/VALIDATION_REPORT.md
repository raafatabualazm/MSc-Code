# Validation Report — Hybrid Training Patch v2.3

## Scope

This validation covers the source overlay, installer, CPU/unit behavior, and
pipeline command construction. It does not claim that the model has been
trained or that ≥200-instruction pass@k has improved.

## Confirmed fixes

### Dynamic sequence padding

- Supervised targets and decoder prompts are tokenized with `padding=False`.
- The supplied graph collator pads labels with `-100` and prompts to the batch
  maximum only.
- GRPO policy and verified-anchor dataloaders use the same dynamic collator.
- Single-row inference no longer pads prompts to 3,072 tokens.

### Train/evaluation budget consistency

- Default target and long-generation ceilings are both 3,072 tokens.
- The runner rejects a target ceiling greater than any effective gate, rollout,
  or GRPO generation ceiling.
- The Phase-0 token report independently fails on target, generation, or prompt
  overflows.

### Token distribution

The new CPU report includes:

- p50/p75/p90/p95/p99 and extrema;
- historical 768/1024/2048/3072 overflow counts;
- short/bridge/long and training-task breakdowns;
- per-input-file summaries;
- deduplicated complete-code target summaries;
- largest examples and concrete overflow records.

### Ordering

The matched direct-code long baseline and its absolute ≥200 evaluation are run
before the latent graph-causality stop gate. Region-plan training remains behind
that gate.
