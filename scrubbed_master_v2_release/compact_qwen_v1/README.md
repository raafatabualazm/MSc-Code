# Compact Qwen v1 exploratory release

This directory is generated by `scripts/data/build_compact_qwen_v1.py`.

- `compact_model_inputs.jsonl` is the strict model-facing file. Each row has
  only `compact_input_ids` and the codec/codebook/tokenizer SHA-256 bindings.
  `compact_input_ids` contains the compact source only; the decoder prompt is
  added exactly once by the direct-Qwen trainer/inference path.
- `alignment_private.jsonl` contains task IDs, source paths, compact text, and
  audit hashes. It must not be passed to the model.
- `codebook.json` records the train-public-only instruction codebook,
  `base_vocab_size`, and the source-token-to-base-token initialization map.
- `compact_contract.json` binds the codec, codebook, raw and logical tokenizer,
  Qwen config/model/immutable revision, source-token vocabulary, limits, pinned
  DFG extractor, and the neutral target function `candidate`.
- `quarantine.jsonl` contains the 14 opcode-corrupted `local_N` rows.
- `preflight_report.json` records graph round-trip and actual Qwen token gates.

The checked-in full-release fit is explicitly **exploratory**, because the same
public release was used to fit and measure the codebook. Confirmatory builds
must pass distinct `--fit` and `--measure` files. A measure file never changes
the fitted codebook.

The canonical directory uses `runtime-symbol-policy-v1`: self/closure and all
untrusted source helper/type symbols are neutralized, while trusted Dart VM
stubs, `dart:` SDK symbols, and `print` retain runtime meaning. The policy and
the pinned Qwen model config are SHA-bound in the codebook. The
`strict_all_alias_ablation/` subdirectory records the more destructive policy;
it is an ablation, not the canonical input.

## Lossless domain

This is not semantic summarization. It is lossless over the
`scrubbed_canonical_graph` domain: instructions, entry blocks, and CFG edges
round-trip exactly. DFG edges are deterministic redundant data regenerated by
the SHA-pinned extractor and compared edge-for-edge with the scrubbed input.
There is no UNK substitution or truncation; raw-instruction fallback remains
reversible. Privacy scrubbing performed before the codec is the only
intentional irreversibility. The current exploratory build verifies all 2,197
retained rows and 201,091 regenerated DFG edges exactly.
